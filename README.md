# 🎂 Органайзер дней рождения

Desktop-приложение на Python для хранения контактов, отслеживания дней рождения и напоминаний о предстоящих событиях.

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![CustomTkinter](https://img.shields.io/badge/GUI-CustomTkinter-green)
![SQLite](https://img.shields.io/badge/DB-SQLite-lightgrey)

## Описание

Программа помогает не забывать о днях рождения близких людей. Пользователь может добавлять контакты с датой рождения, телефоном, email, фото и эмодзи, получать напоминания и экспортировать данные в CSV.

Поддерживается авторизация пользователей и роль администратора для управления учётными записями.

## Возможности

- Регистрация и вход пользователей
- Добавление, редактирование и удаление контактов
- Автоматический расчёт возраста и количества дней до ближайшего дня рождения
- Напоминания о предстоящих днях рождения (настраиваемый период)
- Подсветка контактов с ДР сегодня и в ближайшие 3 дня
- Два режима отображения: таблица и список + детали
- Загрузка фото контакта
- Экспорт данных в CSV
- Панель администратора (удаление пользователей, сброс пароля)

## Требования

- Windows 10/11 (или другая ОС с поддержкой Tkinter)
- Python 3.10 или новее

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/<username>/birthday-organizer.git
cd birthday-organizer
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python main.py
```

## Учётная запись по умолчанию

При первом запуске создаётся администратор:

| Поле    | Значение   |
|---------|------------|
| Логин   | `admin`    |
| Пароль  | `admin123` |

> Рекомендуется сменить пароль после первого входа.

## Горячие клавиши

| Комбинация   | Действие              |
|--------------|-----------------------|
| `Ctrl+N`     | Новый контакт         |
| `Ctrl+D`     | Удалить контакт       |
| `Ctrl+R`     | Проверить напоминания |

## Сборка exe (опционально)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name BirthdayOrganizer main.py
```

Готовый файл появится в папке `dist/`.

## Сборка установщика (опционально)

Для Windows можно использовать Inno Setup и файл `installer.iss`.

## База данных

Используется SQLite (`birthdays.db`). Таблицы:

- `users` — пользователи и роли
- `contacts` — контакты с днями рождения
- `settings` — настройки напоминаний

## Технологии

- **Tkinter / ttk** — таблицы, меню, диалоги
- **SQLite3** — локальное хранение данных
- **Pillow** — работа с изображениями
